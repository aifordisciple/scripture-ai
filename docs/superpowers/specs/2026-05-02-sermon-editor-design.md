# 我的讲章 — 功能设计文档

**日期**: 2026-05-02
**状态**: 已确认

## 概述

"我的讲章"是一个 AI 加持的讲章预备与管理系统，帮助牧师和传道人高效预备讲章。入口在头像菜单中，点击后打开讲章标签页。

## 目标用户

混合用户群：主日讲道牧师、多场景传道人、神学生/初学者。优先级依次递减，设计需兼顾引导性与高效性。

## 界面布局：全屏编辑 + 图标侧栏

采用类似 Notion/Cursor 的布局：

- **极窄图标侧栏**（~40px）：切换不同侧面板
- **主编辑区**：全屏 Tiptap 富文本编辑器，内容居中显示（max-width ~760px）
- **侧面板**：按需从右侧滑出，一次只显示一个

### 图标侧栏项

| 图标 | 面板 | 功能 |
|------|------|------|
| 📚 | 讲章列表 | 文件夹分类树、标签筛选、搜索排序、增删改查 |
| 🤖 | AI 助手 | 深度对话、上下文感知、一键插入、快捷指令 |
| 📖 | 经文参考 | 关联经文全文、交叉引用、原文词义、内联插入 |
| 📋 | 模板 | 预置模板（释经式/主题式/叙事式）、自定义模板 |
| ✅ | 讲章审查 | 释经准确性、逻辑连贯性、福音焦点、应用建议、时间预估 |
| ⚙️ | 设置 | 讲章相关偏好设置 |

### 编辑器顶部元数据栏

显示讲章标题、风格标签（释经式/主题式/叙事式）、讲道日期、关联经文引用、自动保存状态。

## 工作流：双入口汇合

### 入口一：从经文开始

1. 选择经文（书卷+章节+节）
2. AI 深度分析经文（原文词义、历史背景、神学主题、交叉引用）
3. 提炼讲章主题
4. 汇合到共同流程

### 入口二：从主题开始

1. 输入讲章主题/方向
2. AI 推荐相关经文
3. 选定经文
4. 汇合到共同流程

### 共同流程

1. **AI 大纲生成** — 根据经文+主题+风格生成讲章大纲，牧师可调整/重组/增删
2. **自由写作 + AI 辅助** — 在 Tiptap 编辑器中自由写作，AI 提供内联辅助
3. **AI 审查反馈** — 完成后 AI 审查讲章质量
4. **完成** — 保存讲章

## 编辑器：Tiptap 富文本编辑器

### 核心功能

- 富文本编辑：标题、段落、列表、引用、粗体/斜体
- 经文内联块：在编辑器中内联显示圣经经文，带蓝色左边框样式
- 自动保存：内容变更后自动保存到数据库
- 讲章元数据：标题、风格、日期、关联经文作为结构化字段

### 内联 AI 操作

选中文字后弹出浮动工具栏：

| 操作 | 功能 |
|------|------|
| ✨ 续写 | AI 续写选中段落后的内容 |
| 📝 润色 | AI 润色选中文字的表达 |
| 📖 插经文 | AI 查找并插入相关经文引用 |
| 💡 补例证 | AI 补充例证/见证 |
| 🔗 交叉引用 | AI 查找交叉引用经文 |

AI 操作结果直接插入编辑器，牧师可接受/拒绝/修改。

## 侧面板详细设计

### 📚 讲章列表

- 文件夹分类树（可展开/折叠）
- 标签筛选（多标签 AND 逻辑）
- 搜索（标题+内容全文搜索）
- 排序（日期/标题/状态）
- 右键菜单：重命名、移动、删除、复制
- 新建讲章按钮（触发双入口选择）

### 🤖 AI 助手

- 对话式交互，上下文自动关联当前讲章
- 预设快捷指令：
  - "分析这段经文的原文含义"
  - "为这个论点补充圣经依据"
  - "帮我构思应用的切入点"
  - "这段表达如何更贴近会众"
- AI 回复中的建议可一键插入编辑器
- 对话历史随讲章保存

### 📖 经文参考

- 关联经文全文显示（CUV/KJV 双语）
- 交叉引用链（点击展开）
- 原文词义（希伯来/希腊语解析）
- 一键插入经文到编辑器（作为内联块）

### 📋 模板

- 预置模板：
  - 释经式讲章（经文→背景→释义→应用→结语）
  - 主题式讲章（主题→经文依据→论证→应用→呼召）
  - 叙事式讲章（故事→转折→启示→应用）
- 自定义模板：从已有讲章创建，或从零构建
- 模板包含：结构框架 + 提示文字 + AI 引导

### ✅ 讲章审查

- 释经准确性：检查释经是否有依据，是否过度灵意化
- 逻辑连贯性：分析论点之间的逻辑链条
- 福音焦点检测：是否指向基督
- 应用落地建议：应用是否具体、可操作
- 时间预估：根据字数估算讲道时长
- 生成附属内容：讲道摘要、讨论问题、祷告要点

## 数据模型

### Sermon（讲章）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | UUID |
| userId | String | 所属用户 |
| title | String | 讲章标题 |
| content | Json | Tiptap JSON 内容 |
| folderId | String? | 所属文件夹 |
| style | Enum | 释经式/主题式/叙事式/自由 |
| status | Enum | 草稿/进行中/已完成 |
| sermonDate | DateTime? | 讲道日期 |
| verseRefs | Json | 关联经文引用数组 [{bookId, chapter, verseStart, verseEnd}] |
| tags | String[] | 标签 |
| aiChatHistory | Json? | AI 对话历史 |
| wordCount | Int | 字数 |
| estimatedMinutes | Int? | 预估讲道时长 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### SermonFolder（讲章文件夹）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | UUID |
| userId | String | 所属用户 |
| name | String | 文件夹名称 |
| parentId | String? | 父文件夹 ID（支持多级） |
| sortOrder | Int | 排序序号 |
| createdAt | DateTime | 创建时间 |

### SermonTemplate（讲章模板）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | UUID |
| userId | String? | 所属用户（null 为系统预置） |
| name | String | 模板名称 |
| description | String? | 模板描述 |
| style | Enum | 释经式/主题式/叙事式/自定义 |
| structure | Json | 模板结构（Tiptap JSON） |
| isDefault | Boolean | 是否为系统预置 |
| createdAt | DateTime | 创建时间 |

## API 路由

### /api/sermon — 讲章 CRUD

- `GET` — 列表查询（支持 folderId、tag、search、status 过滤）
- `POST` — 创建讲章
- `PUT` — 更新讲章
- `DELETE` — 删除讲章

### /api/sermon/folder — 文件夹 CRUD

- `GET` — 获取用户所有文件夹（树形）
- `POST` — 创建文件夹
- `PUT` — 重命名/移动
- `DELETE` — 删除文件夹（讲章移至根目录）

### /api/sermon/template — 模板 CRUD

- `GET` — 获取模板列表（系统+用户自定义）
- `POST` — 创建自定义模板
- `PUT` — 更新模板
- `DELETE` — 删除自定义模板

### /api/sermon/[id]/review — AI 审查

- `POST` — 触发 AI 审查，返回审查报告

### /api/sermon/[id]/ai-chat — AI 对话

- `POST` — 发送消息，AI 回复（流式）

## 与现有系统的集成

- **头像菜单**：添加"我的讲章"菜单项，点击打开 `type: 'sermons'` 标签页
- **阅读页**：选中经文后可一键"创建讲章"，自动带入经文引用
- **AI 侧边栏**：现有 sermon 模式的提示词和 API 可复用
- **经文数据**：复用现有 BibleVerse 数据和搜索 API
- **标签页系统**：在 Tab 类型联合中添加 `'sermons'`
